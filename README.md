I have been paid to write software since 2012. I started with Oracle PL/SQL and Forms & Reports and today I work mostly in TypeScript, NestJS and React. Most of those years were in telecom, building corporate software.

One thing I noticed about my career: I usually end up building the base the rest of the team works on. A screen standard here, an ACL API that outlived two companies there. I also learned the hard way what over-engineering does to a large codebase, so I treat every new abstraction as suspicious until it earns its place.

Outside work I build and run [GlamSpot](https://glamspot.com.br), a booking platform for beauty salons. 22,000 salons listed, paying customers, one developer.
